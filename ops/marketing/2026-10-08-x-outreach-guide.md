## 2. アカウントの探し方（Xの検索とリストだけで手作業）

### 2-1. 基本の手順
1. Xの検索窓にキーワードを入れる
2. タブを使い分ける
   - **最新**: いま悩んでいる人（購入検討者）を探す。返信先はここから
   - **ユーザー**: 比較・レビューを継続して書いているアカウントを探す。フォロー先はここから
3. 良さそうな人はプロフィールと直近の投稿を10件ほど見てから判断する（すぐフォローしない）
4. 良い対象は「リスト」に入れる（後述）

### 2-2. 検索キーワード例
実在アカウント名はここに書きません。以下の語句で、ご自身で検索してください。

| 目的 | 検索語の例（組み合わせて試す） |
|---|---|
| 迷っている人（返信先） | 「Fire TV Stick 違い」「Kindle どれ買う」「ドライヤー 比較」「ロボット掃除機 どれがいい」「イヤホン 迷ってる」 |
| セール前の悩み | 「プライム感謝祭 何買う」「ブラックフライデー 何買う」「初売り 狙い目」「新生活 家電 何から」 |
| 型番ワード（当サイトの記事に近いもの） | 「マグニフィカ スタート 違い」「ナノケア EH-NA0K」「Apple Watch SE3」「Smart Band 10」「Liberty 5」（`keywords-2026-10-07.md` 参照） |
| 比較・レビューを書く人（フォロー先） | 「比較してみた」「スペック比較」「買ってよかった」「買い替え 検討」 |
| 絞り込みのコツ | 語句を引用符で囲む／「min_faves」等の検索演算子は使えるかXの現行仕様を確認して使う／直近の投稿に絞る |

ヒント: 検索窓の「保存した検索」に登録すると毎日打ち直す手間が減ります（機能の有無は現行のXで確認）。

### 2-3. 良い対象・避ける対象

| 良い対象（優先） | 理由 |
|---|---|
| 同じ悩みを書いている購入検討者 | 当サイトの比較記事が直接役に立つ。返信が自然 |
| 比較・レビューを書く中規模アカウント（目安：フォロワー数百〜数万、自分の言葉で書いている） | 同じ関心の読者がいて、交流が長続きしやすい |
| 家電・ガジェット・コスメ・日用品・本の話題を継続して投稿している人 | 当サイトのカテゴリと合う |
| メーカー公式・ニュース系 | **フォローのみ**。最新情報の収集用。リプライで宣伝しない |

| 避ける対象 | 見分け方 |
|---|---|
| フォロー返し目的の「相互」アカウント | プロフィールに「相互」「フォロバ100%」。投稿が宣伝・告知だらけ |
| 懸賞／RTキャンペーン系 | 「RTで当たる」が中心。購入検討者ではない |
| 煽りアカウント | 「今すぐ買わないと損」「絶対買え」など。関わると当サイトの印象も下がる |
| 誹謗中傷・炎上狙い | 投稿が攻撃的 |
| 他社のアフィリエイトリンクだけ連投しているアカウント | 会話にならない |

### 2-4. リストで整理する
Xの「リスト」（非公開で作る）を作り、毎日そこを見る運用にすると、タイムラインに流されません。

| リスト名（例） | 入れる人 | 使い方 |

## 3. 毎日のルーティン（15〜20分）

最初のうちの目安です。無理に達成せず、質を優先してください。

| 手順 | 時間 | 目安 | やること |
|---|---|---|---|
| 1. リスト・保存検索を見る | 5分 | - | 新しい悩み投稿、比較投稿を探す |
| 2. フォロー | 3分 | 約5人／日 | プロフィールと直近投稿を確認してから |
| 3. リプライ | 8分 | 約3件／日 | 役に立つときだけ。無ければ0件でよい |
| 4. いいね／引用 | 2分 | 数件 | 本当に良い投稿だけ。引用は感想や補足を添える |
| 5. 自分の投稿への返信確認 | 2分 | - | もらった返信には丁寧に返す |

注意:
- **これは開始時のゆるい目安です。** Xにはフォロー数・投稿数・短時間の連続操作に対する制限や、スパム判定のルールがあります。現行ルールをオーナー自身で確認し、制限に近づく使い方をしないでください
- 一日のうちに時間帯を分けて少しずつ行う方が自然です
- 警告・制限が出たら、数日操作を止めて原因を見直す（このファイルの数字より安全側に倒す）
- フォロー数の増やし方を急がない。フォロー数とフォロワー数の極端な差は避ける意識を持つ

## 4. リプライのテンプレート

共通ルール:
- 相手の投稿の内容に合わせて毎回書き換える。**同じ文面のコピペ返信はしない**
- **返信にAmazonリンクは貼らない。** 返信内で商品を売らない
- 当サイトの記事URLは、**質問に直接答える記事があるときだけ**。そのとき文末に **#PR** を入れる（記事自体にも「本ページはプロモーション（広告）を含みます」の表記あり）
- 「使ってみた」「実際に使っている」など、使っていない商品を使った体験として書かない。根拠は「公式スペック」「公開されている口コミの傾向」と明記
- 口コミや数値を作らない。確認できていないことは「公式で確認してみてください」と言う
- DMにリンクを送らない。DMで営業しない
- 返信は短く。相手の質問に答える内容を主役にする

### テンプレA：質問に事実で答える（リンクなし）
> 〇〇と△△で迷われているんですね。公式スペックを見ると、違いは主に「（例：操作方法）」と「（例：サイズ）」のようです。置き場所が決まっているなら、まず寸法を確認すると絞りやすいかもしれません。

### テンプレB：判断の軸を渡す（リンクなし）
> 予算が（例：2万円台）なら、先に「何に一番使うか」を決めると選びやすいです。（例：動画視聴中心→画質と対応アプリ／持ち運び重視→重さ）。ご用途を教えてもらえれば、見るポイントを一緒に整理できます。

### テンプレC：記事が直接答えるとき（リンクあり・#PR）
> 〇〇と△△の違いを、公式スペックを表にまとめた記事があります（私たちは実機は使っておらず、スペックと公開情報の比較です）。ご参考まで。
> （正式URLの記事ページ）
> #PR

- 使うのは、相手の質問と記事のテーマが一致するときだけ。1日1件以下が目安。無理にリンクを入れない

### テンプレD：購入済みの人への共感（リンクなし）
> 購入おめでとうございます！ 届くのが楽しみですね。設定のコツなどあればまた共有してもらえたら嬉しいです。

### テンプレE：わからないときの誠実な返答
> 私たちはスペック比較の立場で、その点は公式の説明で確認できていません。メーカーの公式ページかサポートで確認されるのが確実だと思います。

## 5. 絶対にやらないこと

| NG | 補足 |
|---|---|
| 大量フォロー／大量アンフォロー | Xのスパム規約に抵触しうる。フォロー返し目当ての運用はしない |
| 自動化ツール・ボット・自動いいね／自動返信 | 手作業のみ。Xの自動化ルールに違反しうる |
| フォロワーの購入、相互フォロー集団への参加 | 質が下がり、アカウントの信用も損なう |
| 同じ文面の繰り返し返信 | スパム判定の恐れ。相手にも失礼 |
| Metricoolの利用 | アフィリエイト用ブランド未設定のため、閲覧・予約・投稿・分析のすべて禁止。既存ブランドは別案件用で触らない |
| Amazonリンクを返信・DM・固定ポスト・プロフィールに貼る | 返信とDMはもちろん、メール・LINE・PDFなどオフライン資料にも貼らない。当サイトの記事へのリンクを使う |
| 実機レビュー・「使ってみた」と書く | 使っていない商品は「スペック比較」「口コミ分析」 |
| 口コミ・レビュー・数字の捏造 | 根拠がなければ書かない／「要確認」 |
| 「最安」「絶対安い」などの断定的な価格表現 | 価格は「記事作成時点（日付）」を添える |
| 「必ず儲かる」風の煽り、他社・他人への攻撃 | 評判を落とす |

### Amazonアソシエイトのルール（SNS関連）
- アソシエイト・セントラルに登録済みのサイト・SNS欄は現在「未設定」（`ops/config.md`）。**オーナーが X @dreamtactselect をアソシエイト・セントラルに登録・確認してから**、Amazon関連の投稿（記事への誘導を含む）を運用すること。登録手順と現行規約はアソシエイト・セントラルで確認
- 登録したアカウント以外（個人アカウント、別アカウント）でアソシエイトリンクの案内を行わない
- 広告であることを明記する（#PR、または「広告を含みます」）。ステマ規制への対応
- 規約は改定される（2026-04-20に運営規約の改定あり）。最新の規約をオーナーが確認する
