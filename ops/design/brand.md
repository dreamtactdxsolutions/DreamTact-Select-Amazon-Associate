# DreamTact Select ブランドルール

作成: designer（2026-10-07）／出典: `src/index.css` の CSS変数、`index.html` のフォント読み込み
このルールは画像クリエイティブ（アイキャッチ・バナー・SNS画像）とサイト部品の両方に使う。

## 1. 色

サイトの既存トークンをそのまま使う。新しい色を足すときはこの表に追記してから使う。

| 役割 | トークン | 値 | 使いどころ |
|---|---|---|---|
| 背景（基本） | `--bg-primary` | `#0a0f1d` | 画像の地色、ページ背景 |
| 背景（面） | `--bg-secondary` | `#111827` | カード、パネル |
| 背景（強調面） | `--bg-tertiary` | `#1f2937` | カード内の区切り、ラベル地 |
| 枠線 | `--border-color` | `#374151` | 区切り線、カード枠 |
| 文字（主） | `--text-primary` | `#f3f4f6` | 見出し・本文 |
| 文字（副） | `--text-secondary` | `#9ca3af` | 補足、サブコピー |
| 文字（弱） | `--text-muted` | `#6b7280` | 注記、日付 |
| アクセント（ゴールド） | `--accent-primary` | `#d4af37` | ブランドの主アクセント。強調語、区切り、VSマーク |
| ゴールド（明） | `--accent-primary-hover` | `#f3cf55` | グラデーションの明部、ホバー |
| ゴールド（暗・グラデ用） | — | `#b8860b` | `.gradient-gold-text` の暗部 |
| アクセント（青） | `--accent-secondary` | `#3b82f6` | 比較の「もう一方」、リンク、情報バッジ |
| 成功（緑） | `--accent-success` | `#10b981` | 「対応」「○」など肯定の表示のみ |

運用ルール
- 1枚の画像で使うアクセントは **ゴールド＋青まで**。緑は比較表の○表示などに限る。
- 2商品の比較画像では、**A＝ゴールド、B＝青** で色分けし、どちらが上という意味を持たせない。
- 文字と背景のコントラストは 4.5:1 以上（濃紺地に `#f3f4f6`／`#d4af37` は可。`#6b7280` は注記の小さい文字だけに使う）。

## 2. フォント

- サイト: `'Outfit', 'Inter', 'Noto Sans JP', sans-serif`（Google Fontsで読み込み済み）
- 画像（SVG）: 日本語を含む文字は `font-family="'Noto Sans JP', sans-serif"`。英字ロゴ部分のみ `'Outfit', 'Noto Sans JP', sans-serif` を使ってよい
- ウェイト: 見出し 700〜900、本文 400〜500、注記 400
- 画像の文字サイズ目安（1200×630）: メイン見出し 64〜84px、サブ 40px以上、サイト名・補足 28px以上、PR 36px以上。スマホのSNSカード表示では約0.3倍（360px幅）に縮小されるため、28px未満の文字は置かない（2026-10-07 compliance 指摘で改訂）
- SVGはフォント未インストール環境で代替フォントになる。書き出し時（PNG化）は Noto Sans JP が入った環境で行う

## 3. ロゴ（サイト名）の使い方

- 表記: `DreamTact Select`（文字ロゴ。専用のロゴ画像は現時点で無い）
- 画像では下部か隅に置く（1200×630で28px以上、`--text-secondary` か ゴールド）
- 他社ロゴと並べない、他社ロゴ風に加工しない

## 4. ボタンの文言

- 購入導線は **文字だけ**：「Amazonで詳細を見る」を標準にする
  - 可: 「Amazonで詳細を見る」「Amazonで価格を確認する」
  - 不可: 「最安値で買う」「今すぐ購入（No.1）」など根拠の無い表現、Amazonロゴ・スマイルマーク入りのボタン
- サイト内の遷移: 「詳細を見る」「比較表を見る」「記事を読む」
- 現状の差分（改善案、コード変更はオーナー承認後）:
  - `ProductCard.tsx` の「Amazonでチェック」→「Amazonで詳細を見る」に統一を提案
  - `CompareTable.tsx` の「Amazon」だけのボタン →「Amazonで見る」など動作がわかる文言を提案
  - `.btn-amazon` が Amazon のブランドオレンジ（`#ff9900`）を使っており、公式ボタンに見える恐れがある。ゴールド系（`--accent-primary`）か中立色への変更を提案（要オーナー判断）

## 5. PR・広告表記の置き方

- 記事本文: 冒頭に「本ページはプロモーション（広告）を含みます」（CLAUDE.md の絶対ルール）
- アイキャッチ・バナー・SNS画像: 広告を含む記事・投稿に使うものは **左上か右上に「PR」** を入れる
  - 角丸のラベル、約110×56以上、文字 36px以上・太字、白地（`#f3f4f6`）に濃紺（`#0a0f1d`）の文字などはっきり目立つ配色にする。主要文字の範囲（1200×630なら中央1040×480）の内側に置く（隠れる・読めない置き方をしない）
  - SNSでは画像に加えて投稿文にも「#PR」または「広告」を入れる
- 商品カード・比較表: 近くに「PR」または「広告」のラベルを置く（改善案として扱う）

## 6. Amazon商標・画像の扱い

- Amazonのロゴ、スマイルマーク（矢印）、Amazon風の配色（黒＋オレンジの組み合わせ）を、公式に見える形で使わない
- 「Amazon」は文字として、ボタン文言や説明の中でだけ使う
- Amazonの商品画像は保存・加工・再アップロードしない。サイトで使えるのは SiteStripe／PA-API が返す画像リンクだけ
- バナー・アイキャッチは「商品写真を使わないデザイン」か「オーナーが撮影した写真」に限る
- AI生成画像・素材写真を、特定の商品の実物に見える形で使わない（使う場合は「イメージ」と明記）
- メーカー（例: デロンギ）のロゴも使わない。商品名は文字で書く

## 7. 画像に入れてよい情報

- 価格・割引率は、確認できた数字だけ。入れる場合は **確認日時を画像内か直下に必ず入れる**
- 「最安」「No.1」「一番売れている」など根拠の無い表現は入れない
- 「実機レビュー」「使ってみた」は、オーナーが実際に使った商品だけ。使っていない場合は「スペック比較」「口コミ分析」

## 8. サイズ規格

| 用途 | サイズ | 備考 |
|---|---|---|
| 記事アイキャッチ／OGP | 1200×630 | 重要な文字は中央 1000×500 に収める（SNSでの切り抜き対策） |
| サイト用 横長バナー | 1200×300（暫定） | 設置場所が決まったら更新 |
| SNS 正方形 | 1080×1080 | |
| SNS 縦長 | 1080×1350 | |
